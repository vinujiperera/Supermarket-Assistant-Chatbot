# Basket Buddy - Supermarket-Assistant-Chatbot
An intelligent Chatbot Application for a Supermarket Environment using Natural Language Processing (NLP).The application extracts product names from user-entered sentences and identifies their specific shelf locations within the store.

Features :
NLP extraction - Use spacy tokenization , POS tagging and noun chunking.
Modern GUI - A user friendly GUI built with Tkinter
Database - Supports 17 different grocery items 
Export functionality - Prints the shopping list to a text file for the user.

Installation and Setup :
1. Install spacy 
2. Download the English NLP model

How to run the application :
1. Navigate to the "chatbot.py" file and press the triangular shaped run button at the top right corner.
2. Type the required items in the search bar and click " Find my items" button.
